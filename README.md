# Portfólio Pessoal | Wesley Vinicius Fernandes

Repositório contendo o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minha trajetória profissional, projetos em destaque, formação acadêmica e minha stack de tecnologias.

🔗 **Acesse o portfólio online:** [https://WesleyVinicius.github.io](https://WesleyVinicius.github.io)

## 💻 Sobre o Projeto
Este portfólio foi construído do zero com foco em performance, responsividade e design limpo. Ele atua como um currículo interativo, onde detalho minha experiência de 4 anos no desenvolvimento de sistemas web (focado em Backend com PHP e Laravel), modernização de sistemas legados e integrações.

### 🛠️ Tecnologias utilizadas no desenvolvimento desta página:
* **HTML5** (Semântico)
* **CSS3** (Variáveis nativas e estilização customizada)
* **Bootstrap 5** (Sistema de grids e componentes responsivos)
* **Bootstrap Icons** (Tipografia de ícones)
* **Hospedagem:** GitHub Pages

## 📑 Seções do Portfólio
* **Início:** Apresentação rápida e links para download do currículo em PDF e redes sociais.
* **Sobre Mim:** Resumo da minha trajetória profissional e informações de contato rápido.
* **Projetos em Destaque:** Demonstração de sistemas reais desenvolvidos, como o *Sistema de Sebo (ReLer)* e a *AgroMeta API*.
* **Experiência Profissional:** Linha do tempo detalhando minha atuação na Universidade Estadual de Ponta Grossa (UEPG).
* **Tecnologias & Formação:** Minha stack atual (PHP, Laravel, PostgreSQL, Python, etc.) e minha formação acadêmica (Mestrado e Graduação).

## 🚀 Como executar localmente
Como é um projeto estático, basta clonar este repositório e abrir o arquivo `index.html` em qualquer navegador:

```bash
# Clone o repositório
git clone https://github.com/WesleyVinicius/WesleyVinicius.github.io.git

# Entre na pasta
cd WesleyVinicius.github.io
```
